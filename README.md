# GET 0.1.0 — First Release

## ¿Qué es GET?

**GET (Git Easy Tool)** es un proyecto de gestor de aplicaciones para Windows, diseñado para facilitar la obtención e instalación de programas directamente desde repositorios y publicaciones de plataformas Git, como GitHub y GitLab.

Su objetivo es ofrecer una herramienta sencilla, rápida y accesible desde CMD, permitiendo gestionar aplicaciones mediante comandos cortos, sin tener que navegar manualmente por diferentes páginas de descargas.

GET busca simplificar la distribución de software y centralizar el acceso a aplicaciones publicadas en repositorios Git.

## ¿Qué incluye GET 0.1.0?

Esta es la primera versión pública del proyecto e incorpora las funciones iniciales:

- **GET Help:** sistema de ayuda integrado mediante `get help`.
- **GET Version:** consulta de la versión instalada mediante `get version`.
- **GET Info:** comando inicial para recibir enlaces de repositorios mediante `get info`.
- **CMD Integration:** posibilidad de ejecutar GET directamente desde CMD utilizando el comando `get`.
- **PATH Setup:** instalador para registrar GET en el PATH del usuario de Windows.

## Ejemplos de uso

```cmd
get help
get version
get info https://github.com/usuario/repositorio
```

## Estado del proyecto

GET se encuentra en una etapa inicial de desarrollo.

Las funciones de consulta de publicaciones, descarga e instalación automática de aplicaciones desde GitHub y GitLab están previstas para futuras versiones.

## Objetivo

Crear un gestor de aplicaciones sencillo, independiente y accesible que permita obtener software desde repositorios Git utilizando una interfaz de comandos.
